# SMS – "Kairos" sailing logbook & harbour map

Legacy ASP.NET Core 1.0 RC2 + Knockout.js application (in `SMS/`).

The [`docs/`](docs/README.md) folder documents the legacy application and
specifies its successor: a multi-ship sailing portal (ships, trips with crew,
logbooks, photo/blog timeline with visibility levels, shared costs, automatic
sea routing) built with ASP.NET Core and Angular.
